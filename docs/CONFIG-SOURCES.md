## Not a config key (documented so we do not invent one)

| Claim | How clawscore handles it |
| --- | --- |
| `tools.exec.allowlist` / `allowList` / `allowed` on `openclaw.json` | **Not** in the official Zod schema. Durable command allowlists live in the host exec approvals file ([Exec approvals — advanced](https://docs.openclaw.ai/tools/exec-approvals-advanced)). The scanner still treats a leftover array as heuristic evidence of an allow-list. `fix` never writes this key. |
| Legacy `gateway.bind` host aliases (`0.0.0.0`, `127.0.0.1`, …) | Docs say to use the enum, not host aliases. Detected for older installs; `fix` writes `"loopback"`. |

`fix` does not create tokens, enable sandbox, or delete skills. If a key cannot be edited in place without rewriting the file, it is skipped and a one-line manual change is printed.
